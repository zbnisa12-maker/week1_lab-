1. Page structure

An HTML file is a text file saved with the .html extension. The browser reads it and displays a page.

The head contains information such as the page title. The body contains the content visitors see.

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My website</title>
  </head>
  <body>
    <h1>Hello!</h1>
    <p>Welcome to my page.</p>
  </body>
</html>

Most elements have an opening tag, content and a closing tag: <p>Hello</p>.

2. Headings and paragraphs

Use h1 for the main heading and h2 for a section heading. A p element is a paragraph. Use headings in a logical order.

<h1>About me</h1>
<h2>My hobbies</h2>
<p>I enjoy music and drawing.</p>

Use strong for important text and em for emphasis.

3. Links and images

The a tag creates a link. Its href attribute says where the link goes.

<a href="examples.html">See examples</a>

An image uses img. The src attribute gives the file location, and alt provides a text alternative.

<img src="cat.jpg" alt="A cat sleeping on a sofa">

For this example, put your own cat.jpg in the same folder. The img element has no closing tag.

4. Lists

Use ul for a bullet list or ol for a numbered list. Put each item inside an li element.

<ul>
  <li>Read a lesson</li>
  <li>Try an example</li>
  <li>Take the quiz</li>
</ul>

5. Forms

A form groups input controls. A label tells the user what to enter. Its for value should match the input's id.

<form>
  <label for="name">Your name</label>
  <input id="name" type="text">
  <button type="button">Say hello</button>
</form>

This HTML creates the controls. Making the button do something needs JavaScript or a form destination.
