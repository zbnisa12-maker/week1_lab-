# TagLab — simple version

Упрощённый сайт для изучения HTML: пять страниц, один CSS-файл и небольшой JavaScript для практики и теста.

## Как открыть

Скачай папку целиком и открой `index.html` в браузере. Устанавливать что-либо не нужно. Все ссылки работают между обычными HTML-файлами.

## Где что менять

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная страница |
| `lessons.html` | Все уроки на одной странице |
| `examples.html` | Примеры кода и готовый результат |
| `practice.html` | Три задания на пропущенные теги и атрибуты |
| `quiz.html` | Тест из пяти вопросов |
| `style.css` | Цвета, размеры, карточки и мобильная версия |
| `script.js` | Проверка ответов и подсчёт баллов |

Текст находится прямо в HTML. Цвета и отступы заданы обычными CSS-правилами. Меню повторяется в каждом HTML-файле, поэтому при изменении названий или ссылок нужно обновить все пять страниц.

В `script.js` два блока: первый проверяет задания, второй — тест. `getElementById` находит элемент по его `id`. Обработчик `submit` запускает проверку, а `preventDefault()` отменяет перезагрузку страницы. Цикл `for` сравнивает ответы, переменная `score` считает баллы, а `textContent` выводит результат. Правильные ответы перечислены в массивах `answers`.

При изменении вопросов в HTML обновляй ответы в соответствующем массиве. Для вариантов теста сравнивается значение `value` выбранного переключателя.

Нет фреймворков, сторонних библиотек, онлайн-редактора, регистрации или сохранения прогресса. Результаты сбрасываются после перезагрузки. Все ресурсы локальные, поэтому сайт работает без интернета.
