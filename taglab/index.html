Do I need any coding experience?

No. Start with the first lesson and learn one concept at a time. Each lesson includes an example you can open in the playground.

What do I need to get started?

A browser and a little curiosity. The playground is ready when you are. Later, you can write HTML in any text editor and open the file in your browser.

What will I be able to build?

A simple personal page with text, links, images and a clear structure. HTML gives your page meaning; CSS controls how it looks.
